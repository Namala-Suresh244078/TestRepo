Description

As a Form Author, I want the submission endpoint to enforce business validations currently handled by the frontend so that invalid or unauthorized submissions cannot be made by bypassing UI controls.

Acceptance Criteria

The backend validates whether the form is editable before processing a submission and rejects submissions for forms that are in a read-only state.
The backend enforces the form's multiple submission setting and rejects submissions when multiple submissions are not allowed and the user has already submitted.
The backend validates the current user's submission permissions and rejects submissions from users without sufficient access.
The backend validates submission ownership during updates and rejects attempts to modify submissions not owned by the current user.
The backend validates email attachment size limits and rejects submissions that exceed the configured limits.
The backend validates uploaded files, including allowed file types and extensions, and rejects unsupported files.
Rejected submissions return an appropriate error response and are not persisted.

Notes

Backend validations should complement existing frontend validations and not replace them.
Validation failures should prevent persistence of the submission.
Existing behavior for valid submissions should remain unchanged.
